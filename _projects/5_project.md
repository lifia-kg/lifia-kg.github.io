This module is designed to automatically extract structured information from unstructured real estate listings written in natural language. Given that most real estate data on the web is published in textual, descriptive form—especially in Spanish, as in the case of Buenos Aires listings—this tool addresses the challenge of converting free-text descriptions into usable attribute-value pairs.

The system focuses on identifying and extracting relevant property features (such as location, number of rooms, amenities, etc.) and their corresponding values from advertising descriptions. These structured outputs are then integrated into a Real Estate Knowledge Graph, enabling enhanced search, reasoning, and data analysis.

By applying information extraction techniques tailored to real estate domain language, this module transforms unstructured text into a clean, structured format, making it possible to enrich and expand the knowledge graph with precise, machine-readable property data.
